# Southery — website

The Southery landing page: a static site (HTML, CSS, no build step), hosted on Vercel.

- `index.html` — the page
- `styles.css` — styles, using the Southery design system colours and Cabinet Grotesk
- `assets/photos/` — dish photography (800px cards, 1400px backgrounds)
- `assets/logo/` — vector logos converted from the brand logo files
- `assets/fonts/` — Cabinet Grotesk (Regular, Medium, Bold, Extrabold) as woff2

Every push to `main` redeploys the live site.
